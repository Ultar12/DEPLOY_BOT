03 — Process

How an engagement runs

  1. Scope the real constraint

    We name the user, the failure mode, and the smallest version that would already be useful.

  2. Build in the open

    You get working software early — usually a deployable repo, not a slide deck — and we correct course with evidence.

  3. Ship and hand over

    Hosting, env vars, and runbooks are part of the work. If it cannot be restarted by someone else, it is not done.
